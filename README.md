# Bank Management System — C++

A console-based Bank Management System built in C++ 
that demonstrates all core Object Oriented Programming concepts.

## OOP Concepts Covered
- Class and Object
- Encapsulation
- Abstraction
- Single, Multilevel and Multiple Inheritance
- Runtime and Compile Time Polymorphism
- Static Member and Static Function
- Friend Function and Friend Class
- Constructor and Destructor
- Operator Overloading
- Exception Handling

## How to Run
g++ BankManagementSystem.cpp -o bank
./bank

## Tech Stack
Language : C++
Concepts : Object Oriented Programming
